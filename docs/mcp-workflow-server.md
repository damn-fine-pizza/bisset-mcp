MCP Workflow Server\n\nRun locally with STDIO JSON-RPC:\n\n1. Start the server:\n\n   python -m orchestrator.mcp_workflow_server\n\n2. Talk to it over STDIO using line-delimited JSON requests. Example request to start workflow:\n\n   {"method":"workflow.start","params":{"project_meta":{"name":"myproj"}}}\n\n3. Example next question request:\n\n   {"method":"workflow.next_question"}\n\n4. Record an answer:\n\n   {"method":"workflow.record_answer","params":{"question_id":"q-001","answer_text":"MyProj"}}\n\n5. Freeze spec when interview complete:\n\n   {"method":"workflow.freeze_spec"}\n\nSafety: The server does not call any external LLMs and writes only to the repository workspace under orchestrator/mcp_workflow_server/resources and the sqlite DB. Do not run as root.\n
